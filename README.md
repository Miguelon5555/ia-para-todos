# Estrobo Asociación de amigos del Remo - Blog

## Descripción
Blog para la asociación "Estrobo Asociación de amigos del Remo", una organización sin ánimo de lucro dedicada a promover el remo y las actividades náuticas en la comunidad.

## Características
- 4 secciones principales: Noticias de la asociación, Proyectos sociales, Galería de acciones y Eventos
- Formulario de suscripción para nuevos socios
- Diseño temático relacionado con el mar y el remo
- Búsqueda global y filtros por categoría
- Responsive design para móviles y tablets

## Secciones del Blog
1. **Noticias de la asociación**: Últimas noticias e información sobre la asociación
2. **Proyectos sociales**: Iniciativas sociales y comunitarias
3. **Galería de acciones**: Fotos y vídeos de actividades
4. **Eventos**: Próximos eventos y competiciones
5. **Suscripción**: Formulario para nuevos socios

## Tecnología
- HTML5, CSS3 y JavaScript vanilla
- No requiere backend
- Compatible con todos los navegadores modernos
- Implementación de RSS feeds para contenido dinámico

## Instalación Local
1. Clona o descarga el repositorio
2. Abre `index.html` en tu navegador o usa un servidor local
