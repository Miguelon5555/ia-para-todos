# Hosting Recommendations for Estrobo Asociación de amigos del Remo

## Best Free Hosting Options for Nonprofits

### 1. **Netlify** ⭐ (Recommended)
- **Free Plan Features:**
  - 100 GB bandwidth/month
  - 300 build minutes/month
  - 125,000 function invocations
  - 10 GB storage
  - Custom domains with SSL
  - Global CDN
  - Unlimited deploy previews

- **Domain Options:**
  - Purchase domains directly through Netlify ($10-15/year)
  - Use existing domains from other registrars
  - Connect custom subdomains

- **Pros:**
  - Perfect for static sites like this blog
  - Excellent performance and reliability
  - Easy deployment from Git
  - Built-in HTTPS
  - Great for nonprofits

- **Cons:**
  - No completely free domain (need to purchase)
  - Usage limits (generous but exist)

### 2. **DreamHost** (Best for US Nonprofits)
- **Free Hosting for 501(c)(3) organizations:**
  - Free domain for first year
  - Free email hosting
  - Free SSL certificate
  - 50 GB storage
  - Unmetered bandwidth

- **Requirements:**
  - Valid IRS 501(c)(3) or 501(c)(19) letter
  - US-based organization

### 3. **Free For Charity**
- **Features:**
  - Free domain names for nonprofits
  - Free hosting through Cloudflare
  - Microsoft 365 free email for charities

- **Process:**
  - Sign up for Cloudflare account
  - Register on FFC Hosting site
  - Change DNS settings

### 4. **TinkerHost**
- **Features:**
  - 100% free hosting for nonprofits
  - Automatic WordPress installation
  - Unlimited FTP access
  - Free website builder
  - No ads on websites

- **Requirements:**
  - At least 5 visitors per month
  - May need separate domain registration

## Recommended Setup for Estrobo

### Option 1: Netlify + Purchased Domain (Recommended)
1. Deploy to Netlify using the free plan
2. Purchase a domain like:
   - estrobo-remoliveiros.org
   - estrobo-asociacion.es
   - remoliveiros.org
3. Connect domain to Netlify
4. Enable automatic SSL

### Option 2: Free For Charity (If eligible)
1. Apply through Free For Charity program
2. Get free domain + Cloudflare hosting
3. Set up Microsoft 365 for email

## Deployment Instructions

### For Netlify:
1. Create free Netlify account
2. Connect GitHub/GitLab repository
3. Configure build settings:
   ```
   Build command: (leave empty for static site)
   Publish directory: /
   ```
4. Deploy site
5. Purchase and connect custom domain

### Domain Registration Tips:
- **Namecheap.com**: Often has promotions for .org domains
- **Google Domains**: Reliable and user-friendly
- **Porkbun**: Competitive pricing
- Look for ".org" domains as they're perfect for nonprofits

## Estimated Costs:
- **Netlify**: Free (hosting) + $10-15/year (domain)
- **Total annual cost**: ~$10-15 for a professional nonprofit website
